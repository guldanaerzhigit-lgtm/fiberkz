# FiberKZ — помощник монтажника оптических сетей

React + Vite интерфейс для мобильного использования. Включает заявки, локальное сохранение, калькулятор патч-корда, предварительную оценку оптической мощности, диагностику LOS/PON, базу знаний, SQL-схему D1 и стартовый Worker API.

## Запуск
```bash
npm install
npm run dev
```

## Сборка для Cloudflare Pages
```bash
npm run build
```
Опубликуйте содержимое `dist` на Cloudflare Pages.

## Cloudflare D1 + R2 + Worker
1. Создайте D1 database `fiberkz-db`.
2. Выполните `schema.sql` в D1 Console.
3. Создайте R2 bucket `fiberkz-photos`.
4. В `wrangler.toml` замените `REPLACE_WITH_YOUR_D1_DATABASE_ID` на ID базы.
5. Установите Wrangler и запустите `npx wrangler deploy`.

## Статус прототипа
Заявки пока хранятся в localStorage браузера и ещё не синхронизируются с Worker. Перед реальным использованием добавьте авторизацию, роли, проверку прав, ограниченный CORS и защищённую загрузку фотографий. Не вводите персональные данные реальных абонентов до настройки безопасности. Показания мощности — ориентировочные; применяйте нормы оператора и производителя.
